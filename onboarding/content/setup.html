Prerequisites and operating runbook

Start from the included source snapshots

Extract the entire ZIP. Keep sources/OmegaSolider, sources/Mamtzetza and sources/mamtzetza-qaas-tests together. Do not flatten the directories. The code is self-contained in this package; first restore and Docker image pulls require network access.

Install .NET SDK 10.0.203, Docker Desktop with Linux containers and Compose v2, Git and PowerShell 7. Check the versions before proceeding:

dotnet --version
docker version
docker compose version
git --version

Ports 5672, 15672, 8080 and 9090 must be free. Use the dedicated Compose project. Do not stop another learner's stack or delete unrelated Docker volumes.

Build and local tests

dotnet restore sources/Mamtzetza/Mamtzetza.slnx --configfile sources/Mamtzetza/NuGet.config
dotnet test sources/Mamtzetza/Mamtzetza.slnx -c Release --no-restore --logger trx
dotnet restore sources/mamtzetza-qaas-tests/MamtzetzaTests.slnx --configfile sources/mamtzetza-qaas-tests/NuGet.config
dotnet test sources/mamtzetza-qaas-tests/regression/AssertionRegressionTests.csproj -c Release --no-restore --logger trx
dotnet test sources/OmegaSolider/tests/OmegaSolider.ContractTests/OmegaSolider.ContractTests.csproj -c Release --logger trx

Clean end-to-end run

cd sources/mamtzetza-qaas-tests
./scripts/Run-Isolated.ps1 -Reset

The reset is destructive only to the named qaas-onboarding project. The runner polls readiness for up to 120 seconds, captures pre-batch metric values/start time and then executes the batch. Keep the default API flag true for the supplied E2E expectations. Every batch generates fresh IDs; run in isolation to make numeric deltas meaningful.

Evidence and cleanup

Save allure-results/, evidence/baseline.json, evidence/mamtzetza.jsonl, evidence/compose.log, test exit code and TRX. The verification page distinguishes outputs captured for this delivery from instructions to run yourself.

docker compose -p qaas-onboarding down --volumes --remove-orphans
