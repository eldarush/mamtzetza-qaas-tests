Day 5 — Unseen practical and handover

Goal: independently diagnose and repair a newly seeded maintenance fault. Budget: 6 focused hours.

  1. 0–0.5h: instructor prepares an unseen disposable working copy using the separate teacher instructions. The learner receives the new practical brief and the working infrastructure.
  2. 0.5–2h: reproduce, gather evidence and narrow the cause. State observations before proposing code changes.
  3. 2–4h: add a focused regression, show it failing before, repair the bounded defect and run relevant suites plus E2E.
  4. 4–5h: prepare the handover: exact commits and commands, test outputs, CI URL/status, limitations, cleanup command and rollback plan.
  5. 5–6h: reviewer reproduces from your report and asks you to explain contract compatibility, assertion strength, API fallback and release impact.

Assess with the rubric. All five competency gates are required. If the learner cannot complete one gate, record the evidence and a focused retry plan; elapsed time alone is not completion.
